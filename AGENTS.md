# Python Sandbox SDK

- Public API lives in `src/tenki_sandbox/`; generated protobuf/grpc code stays private under `src/tenki_sandbox/_internal/proto/`.
- Python protobuf generation is part of `sdk/sandbox/buf.gen.yaml`; repo `bufgen` patches generated imports back to private package paths. Do not edit generated files manually.
- Tests use fake RPC clients for ergonomics/contract coverage; live E2E should be separate and gated by credentials.
- Live sandbox FS paths must stay inside the session workdir; default guests use `/home/tenki`, not `/tmp`.
- `expose_port` cannot send both slug and expiry; live API rejects `expires_at` when `slug` is set.
- Data-plane RPCs (`Run`, `WriteFile`/`ReadFile`/`Stat`/..., `Dial`, `HostPortTunnel`) live on `SandboxSessionDataPlaneService`, not `SandboxService`. New session-scoped streaming/fs/exec features must route through `GrpcDataPlaneRPC` (bootstrap via `CreateSessionCredential`), never `client._rpc`.
- `SSHGatewayClientService` RPCs go over the Connect protocol (plain HTTPS POST, see `_connect_unary`), matching the Go SDK, with a transparent fallback to the legacy `SSHGatewayService` path for engines predating the #3866 split. Do not add raw-gRPC calls for this service.
- `clone_repo_url` on create is only honored with `enable_opencode=true` (clones async into `~/repo`). Plain git users: `sb.git.clone(...)`; `git.log/diff/checkout` operate on the workdir root only.
- After `resume()` the edge may reset TLS handshakes while Caddy re-applies the session route (~7s window); the readiness probe treats handshake resets as edge-not-ready.
- `exec`/`start` with a relative `cwd` silently breaks the spawn guest-side; the SDK rejects relative `cwd` with `ValueError` (guest fix pending).
- Long-lived sandboxes are a parameter choice, not a missing function: `create(sticky=True)`, `idle_timeout_minutes=…`, `max_duration=…`, plus `extend()`. Cookbook variants should set these knobs instead of adding new API surface.
- Async client lives in `src/tenki_sandbox/aio/` (`AsyncClient`/`AsyncSandbox`, re-exported at top level). It reuses the **same generated grpc stubs** over `grpc.aio` channels — no bufgen/codegen change. Pure helpers (`_convert`, `models`, `errors.map_rpc_error` — duck-typed, handles `grpc.aio.AioRpcError` — `_time`, `_resource_validation`, URL/auth helpers) and request builders (`client.build_create_session_request` / `build_issue_ssh_cert_request`) are shared between sync and async; put shared request-building there, not duplicated, to avoid drift.
- Async transport contract: unary RPCs are `async def` (awaited); server-/bidi-streaming RPCs (`wait_session`, `open_code_run`, `run`, `read_file_stream`, `dial`, `host_port_tunnel`) are plain functions returning an async iterator (consumed via `async for`) — they must NOT be `async def`. Client-streaming (`write_file_stream`) is awaited with an async-iterator request. The `SSHGatewayClientService` Connect path reuses the sync `connect_unary_blocking` via `loop.run_in_executor` (rare calls, no new dep).
- grpc.aio channels bind to the running loop, so `Async*RPC` create the channel/stub lazily on first call (`_ensure_stub`), not in `__init__`. `AsyncSandboxFS` resolves the data-plane rpc per call via an async `resolve_rpc` callable (mirrors the sync `_SessionRPC` deferral) so it picks up a data plane bootstrapped after init.
- Async SSH (`AsyncSandbox.ssh`/`AsyncClient.ssh` → `AsyncSSHConn` in `aio/ssh.py`), `dial` (`AsyncDialConn`), and host-port tunnels (`AsyncHostPortTunnel`/`AsyncResilientHostPortTunnel`) are implemented; `test_async_parity.py` now asserts the async surface is a full superset of sync (no pending set). Async SSH is a raw async `read`/`write`/`close` stream matching the TS/Go SDKs (needs the `websockets` optional extra: `tenki-sandbox[async]`), NOT the sync paramiko `io.RawIOBase` adapter — paramiko is sync-only. Tunnels bridge to real host sockets via `asyncio.open_connection` (reconnect loop is an `asyncio.Task`); `terminated` is an `asyncio.Event`, callbacks fire via `asyncio.create_task` when async.
- Async tests: `asyncio_mode = "auto"` (pyproject) so `async def test_*` needs no decorator. Shared async fakes live in `tests/_async_fakes.py` (imported by absolute name; the tests dir is not a package). Streaming fakes must return async generators, not coroutines.
- High-level exec/stream wrappers that do not expose stdin must send `stdin_close`; only low-level run/start APIs leave stdin open for callers.
- `stdin_close` is not request-stream EOF. Keep the run request stream open for later signal/kill frames; close it only when the run ends/errors.
- `pause()`/`resume()` must clear data-plane endpoint/client/credential state. Background credential renewal stops on `state=PAUSED`; `CREATING`/`RESUMING` stay retryable.
