# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** — do not open a public
issue or pull request for a suspected vulnerability.

Report through GitHub's Private Vulnerability Reporting:
[**Open a security advisory**](https://github.com/LuxorLabs/tenki-sdk-python/security/advisories/new).

Include enough detail to reproduce the issue (affected version, steps, and
impact). We will acknowledge your report, keep you updated as we investigate,
and coordinate disclosure with you once a fix is available.

## Supported Versions

Security fixes are released against the latest published version of the
`tenki` package on PyPI. Please upgrade to the latest release before reporting.
